웹에서 바로 쓰기

파일은 서버로 올라가지 않아요. 이 브라우저 안에서 바꾸고, 결과를 내려받아요.

여기에 파일이나 폴더를 놓으세요 또는 눌러서 고르기 · PDF · 그림(JPG·PNG·HEIC 등) · ZIP · 아무 파일
찍을 때마다 아래 목록에 더해져요

      할 수 있는 일

      놓은 파일에 맞는 단추만 보여요. 결과는 원본과 다른 새 파일이에요.

      PDF로

      그림을 A4 PDF로. 여러 장은 하나로 묶고, 순서·방향·여백도 골라요. 휴대폰은 카메라로 바로 찍어 묶고 카카오톡 등으로 공유해요. 윈도우 프로그램은 한글·워드·엑셀·PPT도 PDF로 바꿔요.

      그림 용량 줄이기

      작게(1024)·보통(1600)·크게(2560) 중에 골라 JPG로. 알림장·메일에 올리기 좋아요. 사진 회전도 바로잡아요.

      PDF 손질

      PDF 여러 개를 하나로 합치고, 쪽을 빼거나 돌리고, 순서를 바꿔요. 쪽 번호·워터마크(한글 가능)를 넣고, 쪽마다 나누거나 JPG 그림으로도 바꿔요. 스캔한 PDF는 용량을 크게 줄여요.

      ZIP 묶기·풀기

      여러 파일·폴더를 ZIP 하나로 묶거나, 받은 ZIP을 풀어요. 한글 이름이 깨진 ZIP도 읽어요.

      윈도우 프로그램

      탐색기에서 파일을 오른쪽 클릭 → 보내기 → 툭. 결과는 원본 바로 옆에 생겨요.

      툭 윈도우용

      윈도우 10·11 · 관리자 권한 없이 설치 · 무료

      무료로 받기 (ZIP)
      1. 받은 Tuk.zip을 오른쪽 클릭 → [압축 풀기…]로 먼저 풀어요.
      2. 풀린 폴더의 Tuk.exe를 두 번 클릭해요. 파란 'Windows의 PC 보호' 창이 뜨면 두 번만 누르면 돼요.
        Windows의 PC 보호알 수 없는 앱의 실행을 막았어요① 추가 정보
        →
        앱: Tuk.exe게시자: 알 수 없음② 실행
        코드 서명을 하지 않은 새 프로그램이라 처음 한 번만 뜨는 창이에요.
      3. 툭 창에서 주황색 [보내기 메뉴에 넣기]를 누르면 끝. 이제 파일 오른쪽 클릭 → 보내기 → 툭 (윈도우 11은 '더 많은 옵션 표시' 먼저). 메뉴는 숫자 키 1~5로도 골라요.
      4. 새 버전은 툭 창 아래 [새 버전 확인]에서 받아요. 하루 한 번 저절로 확인해요.

      안심하고

      • 파일은 밖으로 나가지 않아요. 웹 버전은 브라우저 안에서, 윈도우 프로그램은 PC 안에서 바꿔요. 서버로 올리지 않아요.
      • 원본은 그대로예요. 결과는 늘 새 파일로 만들고, 이름이 겹치면 (2)를 붙여요.
      • 윈도우 프로그램이 인터넷을 쓰는 건 새 버전 확인뿐이에요. 이 사이트의 version.json만 읽고, 받은 새 버전은 SHA-256이 맞을 때만 써요. 이용 기록은 보내지 않아요.
